## Findings
**REV-45 (should)** `page.tsx` `partnerNames().real` vs `src/domain/export/build.ts` `guestsCsvOf`: the two CSV exports write the `lato` of an unnamed partner differently. Invitati writes the letter (real name only, `null` when unset), the complete export writes the fallback "Partner A". Importing the Settings file in Invitati then fails per row ("lato non riconosciuto"), because the import is given `null`. This breaks the AC21 round trip for a partner without first name or label (my code-8 check assumed one shared name source; REV-38's test passes only because it feeds the same names to both). Fix: make `guestsCsvOf` use the same rule (`displayName(..., "") || null`), and add a test that imports the complete-export CSV with `partners {a:null,b:null}`.

**REV-46 (should)** `ImportSheet.tsx:175` and `:311-333`: the undo toast is only fired by the "Fine"/"Annulla importazione" buttons and the no-skipped path. In the done step, Esc, the overlay or the sheet's close button call `onClose` directly: the import stays, with no undo and no confirmation. Fix: in the done step route `onOpenChange` to the same handler as "Fine" (`onClose(); announce(...)`).

**REV-47 (should)** `ImportSheet.tsx:125-131`: "Non ho importato nulla" is not always true. If the request commits and the response is lost (network, timeout), the user presses "Riprova" and the same rows are imported twice (duplicates are only warnings). The batch id is generated by the RPC. Fix (T12 reconcile): client-generated batch uuid passed to `import_guests`, unique per batch, so a retry returns the first result; at least, on an `unreachable` failure say "Controlla l'elenco prima di riprovare".

**REV-48 (nit)** `ImportPreview.tsx:32` and `ImportSheet.tsx:251`: `row.source` is rendered whole; with REV-43 (unclosed quote) it can be megabytes. Cap what is shown (copy keeps the full text). The done list (`ImportSheet.tsx:245`) is not paged like the preview: reuse `ShowMore`.

**REV-49 (nit)** `import-actions.ts:75-106`: validation runs before the session check; do the session first (cheaper rejection, no behaviour for anonymous callers). Also the NUL guard of REV-41 belongs in this server-side revalidation.

**REV-50 (nit)** `ExportButton.tsx:36-43`: the download gives no feedback in Invitati (the menu closes, nothing says a file was saved). A short toast with the file name, like the export panel's "done". `description` is not tied to its button: add `aria-describedby` so the disabled reason is read.

**REV-51 (nit)** `ImportSheet.tsx:86-97`: after choosing a file the text lands in the textarea with no announcement; add `role="status"` "File letto: N righe".

Questions: none.

Test di andata e ritorno in `export.test.ts` riscritto: l'import riceve i nomi calcolati con una regola scritta nel test (nome o etichetta, `null` se vuoto), indipendente da `guestsCsvOf`, e verifica che il file non contenga "Partner"; casi: un partner senza nome, nessun partner con nome (`{a:null,b:null}`), due partner omonimi. Con il vecchio codice i primi due falliscono.
