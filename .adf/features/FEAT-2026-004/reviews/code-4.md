## Verified, no finding
- **Token derivation** (`token.ts`): HMAC-SHA256 over a versioned context + server-generated uuid, 43 chars, `isRsvpTokenShape` anchored without `m` (a trailing `\n` is rejected), secret passed in (never read or logged there). `createLinks`/`rotateLink` generate the id with `randomUUID()` on the server, so the REV-104 invariant holds in the app. Hash lookup in the DB is by sha256, so no secret-dependent comparison is made in app code; `rsvp_link_matches` compares two hashes for a partner of the same wedding (no oracle for strangers).
- **Secret handling**: `readRsvpLinkSecret` throws value-free errors (missing, short, fake in production); read only in `actions.ts` at call time, turned into a fixed message; no `NEXT_PUBLIC_` name, no `server-only` gap that matters (a bare string constant of the PUBLIC fake value is the only thing a client bundle could hold). `.env.example`, `ci.yml` (3 jobs) and `vitest.config.ts` contain only the documented fake value. The proxy bundle does not read `RSVP_LINK_SECRET`.
- **Admin scope**: `ADMIN_ALLOWED_SCOPES` adds only `src/features/rsvp/public-rpc.ts`; the lint fixture proves `actions.ts`, `data.ts`, `limiter.ts`, public form/page paths are rejected, the dynamic import form too, and `public-rpc.ts` accepts alias and relative forms. `admin.ts` and `public-rpc.ts` import `server-only` (the built proxy chunk resolved it; the proxy, now importing both, built at 12:22).
- **`public-rpc.ts`**: three RPCs only, POST (no `get: true`), hash in the body; every error except the exact `invalid_answers` (code and message) becomes `retry`; all `catch` blocks are silent; gate is `null` on any failure (fail-open, the page still decides and counts); malformed token never reaches the DB; absent IP is an explicit null; test "never forwards or logs Postgres messages, token, hash, IP or answers" exists. `ipKeyFor` runs inside the `try`, so a missing secret key cannot throw into the proxy.
- **Proxy**: `x-r2y-theme` deleted from the forwarded headers on every path (the override mechanism drops headers not forwarded) and set only from an approved id for `/rsvp/{43 chars}` after the guards said `next` on a healthy backend (so the gate cannot bypass a redirect/deny/outage rewrite); `x-r2y-backend` handling unchanged; `p_now` from `resolveNow` with the cookie honoured only with `E2E_CLOCK` and no `VERCEL` (tested three ways); `getActiveThemeId` accepts only `isApprovedThemeId`. 429: `Retry-After >= 1`, `private, no-store`, `no-referrer`, `X-Robots-Tag`, static HTML with no user data and no token (tested). `Referrer-Policy: no-referrer` also on the redirect/rewrite/deny responses for `/rsvp/*`; `X-Robots-Tag` comes from `next.config.ts` on all paths and is repeated on the 429.
- **Guards**: `/rsvp` added as a public prefix with `under()` (so `/rsvpx` stays private) and `isPlainPath` (dots, encoded slash, backslash, `//` refused); tested incl. signed-in members. No new decision path other than `next`.
- **Couple actions**: every action does zod `.strict()` on ids, session from cookies, then the USER's client; permission by `has_permission` + the RPC's own check; `getLinkUrl` reads the link through RLS (own wedding only), revoked = `link_not_found`, other-wedding id and unknown id give the same result; `rsvp_link_matches` is definer, `search_path` pinned, execute only `authenticated`, filters by the caller's wedding, `forbidden`/`link_not_found` only; no `select('*')` on `rsvp_links` (REV-105 respected, columns listed everywhere, export too); `failure()` maps only whitelisted messages and returns fixed Italian text; site URL from env, never from the request Host.
- **Export**: JSON gets answers (diet and `diet_note` are intended, AC13) and link STATES only (`id`, targets, dates); no `token_hash`, no secret; `sanitize` removes forbidden keys too; error path drops the cause on purpose (diet note could be in a message). No CSV change in this diff, so the formula-injection note of S1 is still open for R-07 only.
- **Limiter keys**: own HMAC context, IPv6 reduced to /64, IPv4-mapped folded, unparsable text keyed as is without throwing.
