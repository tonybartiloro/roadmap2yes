## Verified, no finding (round 1)
- **Token derivation** (`token.ts`): HMAC-SHA256 over a versioned context + server-generated uuid, 43 chars, `isRsvpTokenShape` anchored without `m` (a trailing `\n` is rejected), secret passed in (never read or logged there). `createLinks`/`rotateLink` generate the id with `randomUUID()` on the server, so the REV-104 invariant holds in the app. Hash lookup in the DB is by sha256, so no secret-dependent comparison is made in app code; `rsvp_link_matches` compares two hashes for a partner of the same wedding (no oracle for strangers).
- **Secret handling**: `readRsvpLinkSecret` throws value-free errors (missing, short, fake on Vercel); read only in `actions.ts` at call time, turned into a fixed message; no `NEXT_PUBLIC_` name. `.env.example`, `ci.yml` (3 jobs) and `vitest.config.ts` contain only the documented fake value. The proxy bundle does not read `RSVP_LINK_SECRET`.
- **Admin scope**: `ADMIN_ALLOWED_SCOPES` adds only `src/features/rsvp/public-rpc.ts`; the lint fixture proves `actions.ts`, `data.ts`, `limiter.ts`, public form/page paths are rejected, the dynamic import form too, and `public-rpc.ts` accepts alias and relative forms. `admin.ts` and `public-rpc.ts` import `server-only` (the built proxy chunk resolved it).
- **`public-rpc.ts`**: three RPCs only, POST (no `get: true`), hash in the body; every error except the exact `invalid_answers` becomes `retry`; all `catch` blocks are silent; gate is `null` on any failure (fail-open, the page still decides and counts); malformed token never reaches the DB; absent IP is an explicit null; a test asserts nothing sensitive is forwarded or logged. `ipKeyFor` runs inside the `try`.
- **Proxy**: `x-r2y-theme` deleted from the forwarded headers on every path and set only from an approved id for `/rsvp/{43 chars}` after the guards said `next` on a healthy backend (the gate cannot bypass a redirect/deny/outage rewrite); `p_now` from `resolveNow`, cookie honoured only with `E2E_CLOCK` and no `VERCEL`; `getActiveThemeId` accepts only `isApprovedThemeId`. 429: `Retry-After >= 1`, `private, no-store`, `no-referrer`, `X-Robots-Tag`, static HTML, no token. `no-referrer` also on redirect/rewrite/deny for `/rsvp/*`; `X-Robots-Tag` from `next.config.ts` on all paths.
