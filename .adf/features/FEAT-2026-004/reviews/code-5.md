## Round 2: new code reviewed (no new findings)
- **Neutral 404 from the proxy** (`src/proxy.ts:185-232`, `neutral-html.ts`): correct and consistent with the arbitration. Malformed token or broken escape → neutral 404 with no DB call; well-formed token + non-blocked gate + `themeId === null` → one `rsvpLoadPage` (counts the failure, BR9) → `neutral` → same 404; `ok`, `retry`, a null gate or a timeout fail open to the page; a working link and a POST never reach the extra call. The gate's `blocked` check still comes first, so the 10th failure is a 404 and the 11th a 429 as in the pgTAP contract. Body is one constant string (`neutralHtml()`), same headers for every cause, `decorate` adds `no-store`/`no-referrer`; tested byte-identical (malformed vs dead), no `<script>`, no token, no `Retry-After`. Guards run first, so outages and redirects are not masked.
- **Page** (`page.tsx`): no `notFound()`/`not-found.tsx` (deleted), `neutral` and bad shape render `LinkUnavailable` in 200 (reachable only when the gate timed out or on a race: the architect's declared residual). `retry` still shows the service page.
- **`public-rpc.ts` projection** (`pickPage`/`pickPerson`, REV-117): the page and the action response are rebuilt from the AC3 keys only, a malformed person turns the whole answer into `retry`, unknown diet values are dropped, `theme_id` is gone from `RsvpPageData`. Fits "mai altri dati" defence in depth; covered by the extended `public-rpc.test.ts`.
- **`public-actions.ts`** runtime argument checks (REV-116) and `answers.ts` `seen_at` ≤ 40 chars: sound; the test confirms a `token` form field is ignored. Note field attributes (`autocomplete`, `spellcheck`, `autocapitalize` off, form `autoComplete="off"`) are tested.
- Small observations, no action: `NEUTRAL_TITLE` and the page's metadata title are the same literal in two places (cheap to share later); `LinkUnavailable` is now a client component and brings the constant HTML string into the client bundle through `neutral-html.ts` (a few hundred bytes). Visual parity of the hand-written 404 with the React neutral view is the designer's check in S3, as the arbitration says.
